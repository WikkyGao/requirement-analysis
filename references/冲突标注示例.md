# 冲突标注示例

> 本文件展示 PRD 中冲突和待确认项的标准标注格式。

---

## 冲突影响分析表（推荐）

当检测到矛盾时，优先用**冲突影响分析表**呈现（含业务影响与建议方案），替代纯文字列举：

```markdown
- **订单删除** 存在 逻辑冲突:

  | 来源 A（旧 PRD） | 来源 B（新 Word） | 业务影响 | 建议方案 |
  |---|---|---|---|
  | 物理删除（不可恢复） | 软删除（可回收站恢复） | 影响客服误删恢复能力 | **推荐 B**，因涉及售后纠纷风险 |

  - 🔴 待确认
```

> prd_generator 会在 conflict 对象含 `source_a`/`source_b` 与 `impact`/`suggestion` 字段时自动渲染成此表格。

## 冲突类型与标注格式

### 1. 描述冲突

同一功能在不同文档中的描述不一致。

**标注格式**:

```markdown
2. **用户注册**
   > ⚠️ 待确认
   > - 版本1: 需求.md - "仅支持邮箱注册"
   > - 版本2: 功能清单.xlsx - "支持邮箱和手机号注册"
```

### 2. 字段类型冲突

同一字段在不同文档中的类型定义不一致。

**标注格式**:

```markdown
| 字段名 | 类型 | 必填 | 说明 | 来源文档 |
|--------|------|------|------|----------|
| phone | string | 否 | 手机号码 | 数据字典.xlsx |
| phone | integer | 是 | 手机号码 | 需求.md |
> ⚠️ "phone" 字段类型冲突: string(数据字典.xlsx) vs integer(需求.md)
```

### 3. 必填项冲突

同一字段在不同文档中的必填属性不一致。

**标注格式**:

```markdown
| 字段名 | 类型 | 必填 | 说明 | 来源文档 |
|--------|------|------|------|----------|
| email | string | 是 | 邮箱 | 数据字典.xlsx |
> ⚠️ "email" 必填项冲突: 数据字典.xlsx 标记为必填，需求.md 未标记必填
```

### 4. 逻辑矛盾

功能描述之间存在逻辑冲突。

**标注格式**:

```markdown
3. **订单取消**
   > 🔴 逻辑矛盾
   > - 需求.md: "仅管理员可取消订单"
   > - 功能清单.xlsx: "用户可自行取消未发货订单"
   > - 建议: 需要明确取消权限规则
```

## 待补充项标注

当功能缺少必要信息时：

```markdown
5. **商品搜索**
   - 描述: 用户可搜索商品
   - 字段: [待补充]
   - 信息来源: 需求.md
   > ⚠️ 待补充: 缺少搜索字段定义（关键词、分类、价格区间等）
```

## 质量评估标注

在附录中使用表格展示 INVEST 评估：

```markdown
### 需求质量评估

| 功能项 | 独立性 | 可协商性 | 价值 | 可估算 | 小巧 | 可测试 | 总分 |
|--------|--------|----------|------|--------|------|--------|------|
| 用户登录 | ★★★ | ★★☆ | ★★★ | ★★★ | ★★★ | ★★☆ | 16/18 |
| 订单取消 | ★★☆ | ★★★ | ★★☆ | ★★☆ | ★★★ | ★☆☆ | 13/18 |

**总体建议**:
- 🟡 "订单取消"缺少验收条件，建议补充
- 🟢 "用户登录"质量良好
```

## 标注规则总结

| 标记 | 含义 | 严重程度 |
|------|------|----------|
| ⚠️ 待确认 | 冲突项，需用户决定 | 中 |
| 🔴 逻辑矛盾 | 逻辑冲突，必须解决 | 高 |
| ⚠️ 待补充 | 缺少必要信息 | 中 |
| 🔄 本次变更 | 增量模式中的变更项 | 信息 |
